# Agent Research Sandbox

An experimental research environment for studying autonomous AI agents, multi-agent interaction, and emergent behavior inside controlled virtual environments.

## Current Status

🚧 Early development

The current implementation includes:

- Django backend
- Agent model
- Virtual world model
- Marketplace resources
- Agent inventory
- Agent wallet
- Action system
- Simulation engine
- Event logging
- Basic autonomous decision engine
